## Ideas Captured

### Player Fantasy (Q1)
- **Role:** Command the entire ecosystem (many plant species)
- **Feel:** Strategist + Caretaker + Nature fights back (A+B+C)
- **Camera:** Top-down, full island/jungle map view

### Verbs — Plants/Jungle (Q2)
- Grow/spread, Attack, Block/entangle, Regenerate, Cooperate
- **Flee** — plants hide; player must protect planted units *(most satisfying)*
- **Mutate** — plants adapt and evolve
- **Multiple soil types** — different buffs per plant (red soil, sand…)
- **Roguelike cards** — upgrade picks with risk

### Verbs — Apes/Civilization (Q2)
- **Militarized** — apes with modern jobs (engineers, workers…)
- **Extract** — taking soil weakens the forest unless recaptured
- **Green protest** — nature-loving apes sabotage the civilization faction *(most satisfying — mirrors plant flee)*

### Core Loop (Q3)
- **Wave length:** One ape assault wave (5–10 minutes, tower defense style)
- **Roguelike cards:** After each wave win — balance frequency to avoid over-buffing
- **Flee:** When **dissatisfied**, plants uproot and run toward the back

### Core Loop — Deep Dive (Q3d–4)

**Plants become dissatisfied because of:**
- Wrong soil type
- Enemy plant neighbors
- Not cared for / fertilized / watered
- **Weather**

**Card balance:**
- **A** — Pick 1 card every 2–3 waves
- **D** — Cards have risk: strong buff but increased plant dissatisfaction

### Weather & Boss (Q5)

**Weather:**
- Rain — water-loving plants recover; desert plants become dissatisfied
- Harsh sun — must water; apes extract faster
- Storm — plants knocked down; apes pause
- **Mold** — debuff/buff depending on species (mushroom allies? normal plants sickened?)

**Boss system:**
- Each boss has a unique mission — mix of A/B/C:
  - A: Mobile factory → concrete tiles
  - B: Bribe plants → mass dissatisfaction
  - C: Suppress green protest

### Win/Loss & Meta (Q9–10)

**Win:** Survive **5 waves** + defeat boss  
**Lose:**

- **All root nest strongholds** are lost

**Run length:** 5 waves × ~5–10 minutes per wave  
**Map:** Fully random each run

### Root Nest Strongholds (Q11)

**Type:** **B — Root Nest** — spawn plants + restore resources  
**Lose:** Forest Core dies OR **all 3 root nests lost**

**Wave 5 Boss:** **B** — Random 1 of 3 Directors each run

## Ideas Generated

**[Core #1]**: Leaf Me Alone — Ecosystem Commander  
_Core Loop_: Pause → plant/care (Dogecoin) → 5–10 min combat → card (every 2–3 waves) → 5 waves → random boss. Random map + biome each run.  
_Novelty_: Plants have mood and flee on foot; apes have modern jobs; no side is purely good — cynical tagline.

**[Mechanic #2]**: Dissatisfaction Flee  
_Core Loop_: Plant dissatisfied (wrong soil, enemy neighbor, no care, weather) → 😤 → uproot and run backward (Tom & Jerry whoosh!).  
_Novelty_: TD where units desert; mirrors HR Ape vs Green Ape internal conflict.

**[Economy #3]**: Dogecoin vs Carbon Credit  
_Core Loop_: In-run Dogecoin from apes → plant/care. Meta Carbon Credit from runs/achievements → unlock clans + skins.  
_Novelty_: Satire on extraction crypto vs carbon markets.

**[Plants #4]**: Biological 4-Role Soil System  
_Core Loop_: 4 soil types × 3 real plants, full ATK/DEF/Buff/Debuff coverage; 4 wildcards; 3 mutation paths; 7 Deadly Sins in-run.  
_Novelty_: Biology drives gameplay (peanut N-fix + allelopathy, Mimosa flee…).

**[Enemies #5]**: Modern Ape Civilization  
_Core Loop_: Multi-role apes attack from all directions, extract soil; PR/HR/Green are favorites; 3 random Director bosses.  
_Novelty_: Corporate jungle satire; billboards increase dissatisfaction.

## Themes and Patterns

- **Nature vs Progress** — no one is pure; only the strong survive
- **Internal conflict on both sides** — plants flee / apes protest
- **Satire economics** — Dogecoin + Carbon Credit
- **Emotional plants** — care = combat strategy
- **Roguelike variance** — map, biome, boss, cards, stats

## Promising Combinations

- HR + flee + PR billboard = comedy core moment every wave
- Permanent soil cards + random map = different terraform each run
- 7 Deadly Sins + clans = wild builds with risk/reward (balance later)
- Lo-fi chill + chibi apes + cynical tagline = unique tone

## Design Pillars

1. **Plants have emotions** — dissatisfaction, flee, care
2. **Satire with bite** — corporate apes, Dogecoin, Carbon Credit
3. **Biology = mechanics** — soil, plants, weather interlock
4. **Short runs, high variance** — 5 waves, random map/biome/boss/cards
